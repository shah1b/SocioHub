# Contributing to Flow

Flow (this repository, SocioHub) is currently in the product definition stage — no application code exists yet. Contributions at this stage are primarily documentation and planning.

## Working on documentation

- Product documentation lives in [`docs/`](docs); the [`README.md`](README.md) links to every document.
- Keep each document scoped to its topic (vision, product surface, AI features, technical constraints, business model, privacy, roadmap) rather than duplicating content across files — link instead of copy.
- Match the existing tone: direct, minimal, no marketing fluff beyond what's already established in [`docs/vision.md`](docs/vision.md).

## Proposing product changes

Open an issue describing the change and which document(s) it affects before submitting a pull request, so the reasoning behind a change to the product definition is captured alongside the diff.

## Commit messages

Use clear, descriptive commit messages that explain *why* a change was made, not just what changed.
