# AI Features

## Smart categorization

Automatically organizes every post into categories, e.g. Football, Technology, Business, Finance, Gaming, Fitness, Travel, Design, Coding, Music, Movies, Science.

## AI summary

- Long videos become a **2-minute summary**
- Articles become a **30-second read**

## AI recommendations

Instead of engagement optimization, Flow recommends creators based on:

- Quality
- Similarity
- User interests

Not addiction.

## Daily digest

Every morning, a single summary of what's new across every connected platform, e.g.:

```
Today's Feed
✓ 6 YouTube uploads
✓ 4 Reddit discussions
✓ 3 News articles
✓ 2 Podcasts
```

Everything important. Nothing unnecessary.

## Smart filtering

User-configurable filters, e.g.:

- Hide spoilers
- Hide politics
- Hide gambling
- Hide crypto
- Hide AI
- Hide NSFW
- Hide clickbait
- Only educational
- Only creators
- Only newest

## AI assistant

Conversational interface for querying the feed directly, e.g.:

- *"What happened in football today?"*
- *"Summarize today's tech news."*
- *"What videos should I watch?"*

## Design principle

Every AI feature in Flow exists to reduce noise and give the user more control over their attention — never to increase time-on-app or engagement metrics. See [`vision.md`](vision.md) for the philosophy behind this constraint.
