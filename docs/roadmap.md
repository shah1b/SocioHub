# Roadmap

## Future features

- AI voice assistant
- Cross-platform search
- Calendar integration
- Podcast hub
- Newsletter aggregation
- Browser extension
- Desktop app
- Smart TV app
- Wearable notifications
- AI-generated learning playlists

## Success metrics

- Daily Active Users (DAU)
- Average session time (kept intentional, not maximized)
- Time saved per user
- Creator engagement
- User retention
- Premium conversion
- User satisfaction
- Attention reclaimed

Note the deliberate framing: session time and engagement are tracked to confirm Flow stays *intentional*, not to maximize them. This mirrors the product's core philosophy — see [`vision.md`](vision.md).
