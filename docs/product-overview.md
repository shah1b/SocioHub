# Product Overview

## Onboarding: user journey

### Step 1 — Create an account

### Step 2 — Connect preferred platforms

Supported at launch:

- YouTube
- Reddit
- X
- RSS
- Twitch
- Podcasts

Planned future support (subject to platform API availability — see [`technical-considerations.md`](technical-considerations.md)):

- Instagram
- Facebook
- TikTok

### Step 3 — Choose interests

Interests are grouped by category, e.g.:

**Sports** — Football, Formula 1, NBA

**Technology** — AI, Apple, Startups

**Entertainment** — Movies, Anime, Music

### Step 4 — Choose creators

Users pick specific creators within their chosen interests. Nobody else appears in the feed. Example:

**Football** — Fabrizio Romano, ESPN FC, The Athletic

**Technology** — Marques Brownlee, Fireship, Linus Tech Tips

**AI** — OpenAI, Anthropic, Hugging Face

### Step 5 — Build your own algorithm

Users configure what to hide and what to prioritize.

**Hide:**
- Politics
- Celebrity drama
- Shorts
- Reels
- Clickbait
- Rage content

**Only show:**
- Long videos
- Educational content
- New uploads
- Creator posts
- Chronological order

## Main screens

| Screen | Purpose |
|---|---|
| **Home** | One clean timeline |
| **Explore** | Discover creators intentionally, not algorithmically |
| **Categories** | Browse by topic — Football, Technology, Science, Finance, Gaming, Music, Movies, Books, AI, Startups, Lifestyle |
| **Creator Hub** | Manage every creator you follow, across every connected platform |
| **AI Assistant** | Ask natural-language questions, e.g. *"What happened in football today?"*, *"Summarize today's tech news."*, *"What videos should I watch?"* |
| **Watch Later** | Save content from any connected platform |
| **Reading Mode** | Distraction-free reading |
| **Focus Mode** | No infinite scroll, no recommendations, no distractions — only selected content |

## Attention modes

| Mode | Behavior |
|---|---|
| **Relax** | Normal feed |
| **Deep Focus** | No reels, no shorts, no autoplay, no notifications |
| **Learning Mode** | Only educational content |
| **Weekend Mode** | Entertainment only |

## UI style

- Modern, minimal
- Dark mode first
- Glassmorphism
- Fast, calm, no visual clutter
